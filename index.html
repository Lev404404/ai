Подключение

В JSON замените нужные значения на плейсхолдеры: {{WIDTH}}, {{HEIGHT}}, {{IMAGE}}, {{SEED}}. Для длительности используйте тот, что подходит вашему узлу: {{DURATION_SEC}}, {{FRAMES_16FPS}}, {{FRAMES_24FPS}}, {{FRAMES_25FPS}}, {{FRAMES_30FPS}}. Числовые поля — без кавычек, строковые (например имя файла) — в кавычках.

Заголовок авторизации (если сервер за прокси)
Запустите ComfyUI с флагом --enable-cors-header — без него браузер заблокирует запросы к серверу. Открывайте эту страницу локально (файл или локальный сервер), а не только через GitHub Pages — иначе https-страница не сможет достучаться до http://127.0.0.1.
